📘 Finance Tracker

Application full-stack de gestion financière personnelle.
	•	Backend : AdonisJS (API REST) + SQLite
	•	Frontend : React + TypeScript + TailwindCSS

⸻

🚀 Fonctionnalités
	•	Authentification (register, login, token)
	•	CRUD des transactions
	•	Catégories
	•	Dashboard simple

⸻

🏗️ Installation

1️⃣ Cloner le projet

git clone https://github.com/<username>/finance-tracker.git


⸻

🛠️ Backend (AdonisJS)

cd backend
npm install
node ace migration:run
npm run dev

➡️ API : http://localhost:3333

⸻

🎨 Frontend (React)

cd frontend
npm install
npm run dev


⸻

🔗 Connexion API

http://localhost:3333/api
